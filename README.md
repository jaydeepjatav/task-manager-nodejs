# Task Manager

A simple Task Manager web application built using Node.js, Express.js, EJS, and Tailwind CSS.

## Features

- Create new tasks
- Add task title and details
- Store tasks as text files
- Display all created tasks
- Read individual task details
- Simple and responsive UI
- Server-side rendering using EJS

## Technologies Used

- Node.js
- Express.js
- EJS
- Tailwind CSS
- File System (fs)
- HTML
